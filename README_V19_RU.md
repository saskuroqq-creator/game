# Yokai V19 — физика воздушного боя

Unity 6000.3.24f1; версия 1.9.0 / Android code 190. Компактный HUD V18 уже встроен в проект.

Launcher: принятый удар подбрасывает Grunt/Ronin/Stalker и героя. Elite можно подбросить после слома стойки. Heavy и Kagane устойчивы к подбросу. Воздушный комбо ограничен тремя ударами; поддержка в воздухе имеет конечный бюджет.

Враг получает вертикальную скорость и горизонтальное отбрасывание. CharacterController разрешает столкновения, гравитация ускоряет падение. Расчёт реакции разбит на шаги до 1/60 секунды; потолок останавливает подъём, боковое столкновение гасит отбрасывание. AI и атаки приостанавливаются до приземления и восстановления. Обычное приземление: 0,42 с; после воздушного удара вниз: 0,85 с.

AirSlam отправляет ближайших доступных воздушных врагов вниз со скоростью 22 м/с, если нет препятствия между ними и героем. Команда падения сама не наносит дополнительный урон: урон остаётся у существующей ударной волны приземления героя. Враг может приземлиться раньше и оказаться вне радиуса волны. Смерть в воздухе сначала завершает падение, затем запускает исчезновение. Сброс врагов очищает все скорости и реакции.

Это управляемая игровая физика через CharacterController, без костного ragdoll. Не требуется менять существующую модель или добавлять Rigidbody поверх контроллера. Для импортированной модели Animator может использовать необязательные параметры Airborne (bool), Landing (bool), VerticalSpeed (float), Staggered (bool). Root motion выключен. Fallback позы реагируют на полёт и приземление, коррекция ног в полёте отключена.

Проверка локально: синтаксис 56 C# файлов и 42 варианта модели HUD прошли. Реальные тесты CharacterController добавлены в Unity release validation: запуск, гравитация, потолок, приземление, иммунитет, сброс и slam при 30/60/120 FPS. Эти Unity-тесты локально не запускались — Unity отсутствует. Физику и удобство жестов необходимо проверить в APK.

Сборка: YOKAI/Build Android APK либо GitHub Actions. APK: Builds/Android/YOKAI_V19_AIR_PHYSICS_RC.apk. CI требует Unity secrets. Источники V18 сохранены в Backups. Проверки на телефоне: Docs/V19_AIR_PHYSICS_PLAYTEST_RU.md.
